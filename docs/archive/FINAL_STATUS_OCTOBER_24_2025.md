## 🎯 قابلیت‌های ML/Analytics فعال

### 1. Collaborative Filtering
```python
# Get recommendations
GET /api/v1/analytics/ml-recommendations/product_recommendations/?limit=10

# Response
{
  "recommendations": [
    {"product": {...}, "score": 0.95}
  ]
}
```

### 2. Content-Based Filtering
```python
# Similar products
GET /api/v1/analytics/ml-recommendations/similar_products/?product_id=UUID

# Response
{
  "similar_products": [
    {"product": {...}, "similarity": 0.92}
  ]
}
```

### 3. Price Optimization
```python
# Optimal price
GET /api/v1/analytics/ml-recommendations/price_optimization/?product_id=UUID

# Response
{
  "current_price": 25000000,
  "optimal_price": 23500000,
  "expected_impact": {"revenue_increase": 12.3}
}
```

### 4. Demand Forecasting
```python
# Forecast 30 days
GET /api/v1/analytics/ml-recommendations/demand_forecast/?product_id=UUID&days=30

# Response
{
  "forecast": [100, 105, 98, ...],
  "trend": "increasing"
}
```

### 5. Customer Segmentation
```python
# Segment users
GET /api/v1/analytics/ml-recommendations/customer_segmentation/

# Response
{
  "segments": [
    {"name": "Champions", "count": 180, "percentage": 12.0}
  ]
}
```

### 6. Fraud Detection
```python
# Detect fraud
GET /api/v1/analytics/ml-recommendations/fraud_detection/?days=7

# Response
{
  "flagged_transactions": 12,
  "fraud_percentage": 1.35,
  "suspicious_transactions": [...]
}
```

## 🎯 دستورات سریع

### Training ML Models
```bash
# Train همه models
python manage.py train_ml_models --model all --days 90

# Train specific model
python manage.py train_ml_models --model collaborative --days 60

# Update recommendations
python manage.py update_ml_recommendations
```

### Testing APIs
```bash
# Get recommendations
curl -H "Authorization: Bearer TOKEN" \
  "https://api.asoud.ir/api/v1/analytics/ml-recommendations/product_recommendations/?limit=10"

# Track event
curl -X POST https://api.asoud.ir/api/v1/analytics/events/ \
  -H "Authorization: Bearer TOKEN" \
  -d '{"event_type":"product_view","object_id":"UUID"}'
```

### CI/CD
```bash
# Pipeline اتوماتیک در GitHub Actions
git push origin main

# Jobs:
# 1. Lint (Black, Flake8, Bandit)
# 2. Security (Safety, pip-audit)
# 3. Test (pytest + coverage)
# 4. Build (Docker image)
# 5. Deploy Staging
# 6. Deploy Production
```
